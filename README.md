# One Card Maze - Algoritmos II (UNIVALI)

## 🎮 Como Jogar
Alcance a saída girando o mapa através da Alavanca para abrir portas. Caixas em cima de portas são destruídas quando rotacionadas.

### Legenda:
* `#` : Parede
* `@` : Jogador
* `O` : Caixa
* `A` : Alavanca
* `S` : Saída
* `=` : Porta A fechada
* `:` : Porta A aberta
* `|` : Porta B fechada 
* `;` : Porta A aberta

### Controles:
* `W` / `A` / `S` / `D` : Movimentação (Cima, Esquerda, Baixo, Direita)
* `R` : Reiniciar
* `Q/E` : Rotacionar em cima da alavanca
* `ESC` : Sair do jogo

## 🚀 Execução
1. Clone o repositório.
```bash
git clone https://github.com/ZigZagR/One-Card-Maze
```

2. Navegue para a pasta que você clonou o jogo.
```bash
cd c:/...
```

3. Compile/Execute o arquivo principal de acordo com a linguagem:
```bash
g++ main.cpp -o jogo.exe
./jogo.exe
```
